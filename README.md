# How to use
1. Install the python dependencies for the server
```pip install flask pillow opencv-python dfpwm soundfile numpy scipy moviepy```

2. Run the server
```python server.py```

3. Modify framer.lua to use whatever URL you want to use.

4. Put it on a CC:T PC with a toms peripheral GPU and a speaker on top.

5. Run framer.lua
